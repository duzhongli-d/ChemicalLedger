## 1. 产品概述

### 1.1 产品定位

面向雅本化学 QC 部门及关联部门（采购、仓库等）的内部技术工具平台，提供化学试剂与实验用溶液的全生命周期管理，以及 QC 专属的文献调研能力。

### 1.2 核心价值

- **台账管理**：试剂从入库到归档的全流程追踪，支持图片扫描录入和过期自动提醒
- **Deep Research**：基于 NotebookLM API 的文献调研工具，帮助 QC 人员快速理解技术文档

### 1.3 技术栈

| 层级 | 技术选型 |
|------|---------|
| 前端 | Next.js + TailwindCSS + i18n（中文/英文） |
| 后端 | FastAPI + SQLAlchemy + Pydantic |
| 数据库 | PostgreSQL |
| AI框架 | LangChain + NotebookLM API |
| 图片OCR | Tesseract OCR + LLM 后处理（或云厂商 OCR） |
| 邮件 | SMTP 或 SendGrid 等邮件服务 |
| 文件存储 | S3/MinIO（存储上传文档和图片） |

## 4. 台账管理功能详细说明

### 4.1 台账创建 — 人工录入

**入口：** `/ledger/create`（需登录）

**字段列表：**

| 字段 | 来源 | 说明 |
|------|------|------|
| 品名 | 人工填写 | 必填 |
| 批号 | 人工填写 | 必填，供应商提供 |
| CAS号 | 人工填写 | 必填 |
| 重量/容量 | 人工填写 | 必填，含单位 |
| 供应商 | 人工填写 | 必填 |
| 数量 | 人工填写 | 单位：瓶，必填 |
| 品类 | 选择器 | 必填，二级品类下拉选择 |
| 证书有效期截止日 | 日期选择器 | 必填 |
| 开封日期 | 日期选择器 | 创建时非必填，后续可补录 |

**系统自动计算字段：**

| 字段 | 计算规则 |
|------|---------|
| 有效截止日 | `MIN(SOP有效期截止日, 证书有效期截止日)` |
| 有效期剩余天数 | `有效截止日 - 当前日期`（动态计算） |
| 内部批号 | `YYYYMMMNNN`，例：`202600501`（2026年第5条，共3瓶）；数量=1时无瓶号：`2026005` |
| 是否开封 | 根据开封日期判断：有开封日期→已开封；无→未开封 |
| 状态 | active / archived |

**SOP有效期截止日计算规则：**

```
已开封：SOP有效期截止日 = 开封日期 + 品类.已开封有效期月数
未开封：SOP有效期截止日 = 创建时间 + 品类.未开封有效期月数
有效截止日 = MIN(SOP有效期截止日, 证书有效期截止日)
```

### 4.2 台账创建 — 图片扫描

**入口：** `/ledger/create/scan`（需登录）

**流程：**

1. **上传图片**
   - 支持格式：JPG/PNG/PDF
   - 单文件 ≤ 2MB
   - 可上传多张图片（最多5张）

2. **OCR 识别**
   - 后端调用 Tesseract OCR 提取文字
   - LLM 后处理：将原始文字转为结构化字段
   - 输出：品名、批号、CAS号、重量/容量、供应商

3. **用户确认**
   - 显示 OCR 识别结果
   - 用户可修正任意字段

4. **补充信息**
   - 数量、品类、证书有效期截止日（必填）
   - 开封日期（非必填）

5. **提交创建**
   - 系统自动计算有效截止日、内部批号等字段

### 4.3 台账编辑

- 创建人可编辑自己创建的台账
- 管理员可编辑任意台账
- 品名、批号、CAS号、重量/容量、供应商、数量、品类、证书有效期截止日可编辑
- 开封日期通过专门入口录入（`/ledger/:id/open`），不在编辑页修改

### 4.4 开封日期录入

**入口：** `/ledger/:id/open`（需登录）

**规则：**
- 普通用户：仅能录入自己创建的台账的开封日期
- 管理员：可录入任意台账的开封日期

**操作后：**
- 系统重新计算 SOP 有效期截止日和有效截止日
- 状态更新（是否开封）
- 记录录入人和录入时间

### 4.5 台账归档

**入口：** 台账明细页「归档」按钮（需登录）

**规则：**
- 普通用户：仅能归档自己创建的台账
- 管理员：可归档任意台账

**归档后：**
- 状态变更为 `archived`
- 记录归档时间和操作人
- 已归档台账不再触发过期提醒

### 4.6 台账搜索与筛选

**筛选条件：**
- 状态：全部 / active / archived
- 品类：一级品类 + 二级品类二级联动
- 创建人：下拉选择

**搜索：**
- 搜索字段：品名、批号、CAS号、内部批号
- 模糊匹配

## 5. 过期提醒功能

### 5.1 触发机制

- **每日凌晨批量扫描**：系统每日凌晨（可配置时间）扫描所有 `status=active` 的台账
- **实时检查**：台账详情页访问时实时计算剩余天数

### 5.2 提醒规则

| 场景 | 判断条件 | 通知对象 | 渠道 |
|------|---------|---------|------|
| 即将过期 | 有效期剩余天数 ≤ 品类.开封提醒阈值天数 | 创建人 | 系统消息 + 邮件 |
| 已过期 | 有效截止日 < 当前日期 | 创建人 | 系统消息 + 邮件 |

### 5.3 系统消息

- 消息类型：`expiry_warning`（即将过期）/ `expiry_alert`（已过期）/ `system`（系统公告）
- 关联台账ID（可跳转至台账明细）
- 已读/未读状态

### 5.4 邮件通知

- 使用 SMTP 或 SendGrid 发送
- 邮件模板包含：台账品名、内部批号、过期日期、剩余天数、操作链接

## 6. Deep Research 功能说明

### 6.1 功能概述

基于 NotebookLM API 的文献调研工具，允许用户上传技术文档（PDF/Word）并通过对话方式提问，获取 AI 回答。

### 6.2 使用流程

1. **上传文档**
   - 支持格式：PDF、Word（.docx）
   - 单文件 ≤ 50MB
   - 最多同时上传 10 个文件

2. **创建 Notebook**
   - 调用 NotebookLM API 上传文档并创建 Notebook
   - 每个用户最多创建 3 个 Notebook（普通用户）/ 不限（管理员）

3. **对话问答**
   - 用户在对话框输入问题
   - 系统调用 NotebookLM API 流式返回 AI 回答
   - 回答基于用户上传的文档

### 6.3 额度规则

| 角色 | 每日提问次数 | 每月文档上传数 | Notebook数量 |
|------|:-----------:|:------------:|:-----------:|
| 普通用户 | 10次 | 5个 | 3个 |
| QC 管理员 | 不限 | 不限 | 不限 |

**每日提问次数重置时间：** 每日 00:00（本地时间）

**计数规则：**
- 用户发起提问（点击发送）即扣减次数，无论回答是否成功
- 流式响应中断不退款

### 6.4 额度展示

- 用户可在 `/profile` 查看当日已用/总次数
- 超额时显示提示，阻止发起新提问

## 7. 通知系统设计

### 7.1 通知渠道

| 渠道 | 实现方式 |
|------|---------|
| 系统内消息 | 存储在 `notifications` 表，用户在 `/notifications` 查看 |
| 邮件 | SMTP/SendGrid，发送到用户注册邮箱 |

### 7.2 通知类型

| 类型 | 触发场景 | 接收对象 |
|------|---------|---------|
| `expiry_warning` | 台账即将过期（剩余天数 ≤ 阈值） | 台账创建人 |
| `expiry_alert` | 台账已过期 | 台账创建人 |
| `system` | 系统公告 | 指定用户或全部用户 |

### 7.3 通知内容模板

**过期提醒（邮件）：**
```
主题：【雅本化学QC平台】台账即将过期提醒

尊敬的 {用户名}：

您的台账「{品名}」（内部批号：{内部批号}）即将于 {有效截止日} 到期，
剩余有效期 {剩余天数} 天。

请及时处理。

查看详情：{台账链接}
```

- 台账列表页：< 500ms 响应时间（数据量 ≤ 10000 条）

- 密码存储：bcrypt 哈希

- 文件上传：格式校验、大小限制
- SQL 注入防护：参数化查询（SQLAlchemy ORM）

### 10.3 可用性

- 支持 Chrome、Firefox、Safari、Edge 最新两个版本
- PC 端优先，移动端可用（响应式布局）

## 12. 附录

### 12.1 内部批号格式说明

```
YYYYMMMNNN
├── YYYY = 4位年份
├── MMM = 3位当年序列号（从001开始，按创建顺序递增）
└── NNN = 2位瓶号（数量>1时显示，如 "03"；数量=1时省略）
```

**示例：**
- `202600501` → 2026年创建，第5条台账，共3瓶中的第1瓶
- `2026005` → 2026年创建，第5条台账，数量为1瓶

### 12.2 名词解释

| 术语 | 解释 |
|------|------|
| SOP | Standard Operating Procedure，标准操作规程 |
| CAS号 | Chemical Abstracts Service registry number，化学物质注册号 |
| NotebookLM | Google 的 AI 笔记研究工具 |
| OCR | Optical Character Recognition，光学字符识别 |
